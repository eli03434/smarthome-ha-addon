# Smart Home Controller

תוסף בקרת בית חכם: שליטה בממסרי Tasmota דרך MQTT, תזמון לפי זמנים הלכתיים,
ניהול משתמשים עם הרשאות גרנולריות, וממשק עברי ללקוח הסופי.

## דרישות מקדימות

1. **Mosquitto broker** — התקן מ-Settings → Add-ons → Add-on Store.
   זהו ה-broker המקומי שאליו מתחברים גם התוסף וגם בקרי ה-Tasmota.
2. בקרי ה-Tasmota שלך מוגדרים להתחבר ל-MQTT של ה-Pi (כתובת ה-IP של HA, פורט 1883).

## התקנה

1. ב-HA: Settings → Add-ons → Add-on Store → ⋮ → Repositories.
2. הוסף את הכתובת: `https://github.com/eli03434/smarthome-ha-addon`
3. מצא את "Smart Home Controller" ברשימה → Install.
4. לחץ Start.
5. פתח את הדשבורד בכתובת `http://<כתובת-ה-HA>:3000`

## הגדרות (Configuration)

| הגדרה | תיאור |
|-------|-------|
| `admin_password` | **חובה — שנה בכל התקנה!** סיסמת האדמין הראשוני. זוהי תמיד מקור האמת לכניסת האדמין; אפשר לשנות אותה כאן בכל עת. |
| `allowed_phones` | **אופציונלי.** מספרי טלפון מורשים לשליטה דרך "ימות המשיח", מופרדים בפסיק (למשל `0501234567,0527654321`). ריק = שליטה טלפונית כבויה. |
| `github_token` | **אופציונלי.** מלא רק אם אתה מהגר הגדרות מהמערכת הישנה בענן. השאר ריק לשמירה מקומית. |
| `github_owner` | בעל ה-repo (רק במצב מיגרציה). |
| `github_repo`  | שם ה-repo (רק במצב מיגרציה). |

המערכת מתחילה עם **משתמש אדמין יחיד**. את שאר המשתמשים (בני הבית, עם
ההרשאות הגרנולריות) האדמין יוצר דרך הממשק לאחר הכניסה. כל ההגדרות
(משתמשים, תוכניות, יומן) נשמרות מקומית בנפח הקבוע של התוסף (`/data`) —
נשמר בין הפעלות ובין עדכונים, ללא תלות בענן.

## חיבור ה-MQTT

התוסף מקבל אוטומטית את פרטי החיבור ל-Mosquitto המקומי דרך Home Assistant —
אין צורך להגדיר כתובת או סיסמה ידנית.

## מכשירי Home Assistant (תאורה, מזגן, תריסים ועוד)

מעבר לממסרי ה-Tasmota, אפשר לחבר לדשבורד כל מכשיר ש-Home Assistant שולט בו
(אורות, מזגנים, תריסים, מנעולים, מאווררים, סקריפטים ואוטומציות):

1. בלשונית **ממסרים** לחץ **➕ הוסף מכשיר מ-Home Assistant**.
2. חפש את המכשיר ולחץ **הוסף לדשבורד**. הוא יופיע בקבוצת "מכשירי Home Assistant"
   לצד ממסרי ה-Tasmota, וניתן להפעיל אותו, לתת לו שם, ולשבץ אותו בתוכניות.
3. שליטה מתקדמת (עמעום אור, טמפרטורת מזגן, מיקום תריס) זמינה דרך כפתור ⚙ שעל הכרטיס.

המצב מתעדכן **בזמן אמת** דרך חיבור WebSocket ל-Home Assistant — שינוי שנעשה
מחוץ למערכת (למשל מאפליקציית HA) משתקף מיד בדשבורד. שמות המכשירים מסונכרנים
אוטומטית מ-HA, אלא אם נתת שם ידני (שאז הוא נשמר).

## פתרון תקלות

- **"שירות MQTT לא זמין"** ביומן → ודא שהתוסף Mosquitto broker מותקן ופועל.
- **הבקרים לא מגיבים** → ודא שה-Tasmota מוגדר ל-MQTT Host = כתובת ה-IP של ה-Pi.
- צפה ביומן התוסף בלשונית **Log**.
