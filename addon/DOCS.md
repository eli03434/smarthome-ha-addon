# Smart Home Controller

תוסף בקרת בית חכם: שליטה בממסרי Tasmota דרך MQTT, שליטה בהתקני Home Assistant,
תזמון לפי זמנים הלכתיים, מצבים ותוכניות, ניהול משתמשים עם הרשאות גרנולריות,
מענה טלפוני דרך "ימות המשיח", וממשק עברי ללקוח הסופי.

## דרישות מקדימות

1. **Mosquitto broker** — התקן מ-Settings → Add-ons → Add-on Store.
   זהו ה-broker המקומי שאליו מתחברים גם התוסף וגם בקרי ה-Tasmota.
   (אם אתה משתמש בברוקר חיצוני — ראה `mqtt_url` בטבלת ההגדרות.)
2. בקרי ה-Tasmota שלך מוגדרים להתחבר ל-MQTT של ה-Pi (כתובת ה-IP של HA, פורט 1883).

## התקנה

1. ב-HA: Settings → Add-ons → Add-on Store → ⋮ → Repositories.
2. הוסף את הכתובת: `https://github.com/eli03434/smarthome-ha-addon`
3. מצא את "Smart Home Controller" ברשימה → Install.
4. מלא את הבקרים בלשונית **Configuration** (ראה למטה) → Save.
5. לחץ Start.
6. פתח את הממשק מ**תפריט הצד של HA** (הכניסה מאובטחת דרך Ingress),
   או ישירות בכתובת `http://<כתובת-ה-HA>:3000`.

## הגדרות (Configuration)

| הגדרה | תיאור |
|-------|-------|
| `admin_password` | **חובה — שנה בכל התקנה!** סיסמת המנהל הראשית. היא תמיד תקפה לכניסה, גם אם שונו סיסמאות בתוך הממשק — ולכן זו תמיד דרך החזרה למערכת אם נשכחה סיסמה. |
| `controllers` | **חובה.** רשימת בקרי ה-Tasmota. לכל בקר: `id` (מזהה פנימי), `name` (שם לתצוגה), `topic` (שם ה-MQTT של הבקר), `relay_count` (מספר הממסרים בו). |
| `yemot_api_token` | **אופציונלי.** טוקן ה-API של "ימות המשיח" — נדרש רק לסנכרון רשימת המורשים ולעדכון קבצי התפריט הקולי. השאר ריק אם אין שליטה טלפונית. |
| `yemot_api_link_url` | **אופציונלי.** כתובת ה-webhook שימות פונה אליה, מסתיימת ב-`/yemot`. דורשת שפורט 3000 יהיה נגיש מהאינטרנט (למשל דרך Cloudflare Tunnel). |
| `mqtt_url` | **אופציונלי.** ברוקר MQTT חיצוני, למשל `mqtt://192.168.1.50:1883`. השאר ריק כדי להשתמש ב-Mosquitto של HA — שמוגדר אוטומטית. |
| `mqtt_user` / `mqtt_pass` | פרטי הזדהות לברוקר החיצוני בלבד. |

### דוגמה להגדרת בקרים

```yaml
controllers:
  - id: main
    name: בית
    topic: tasmota_D3D204
    relay_count: 6
  - id: second
    name: קומה שנייה
    topic: tasmota_6CC008
    relay_count: 8
```

ה-`topic` הוא שם ה-MQTT של הבקר — בממשק ה-Tasmota תחת **Configuration → MQTT**.
הממסרים ממוספרים ברצף לפי סדר הבקרים: בדוגמה למעלה 1–6 שייכים ל"בית" ו-7–14 ל"קומה שנייה".

המערכת מתחילה עם **משתמש מנהל יחיד** (`admin`). את שאר המשתמשים — בני הבית, עם
ההרשאות הגרנולריות — המנהל יוצר דרך הממשק לאחר הכניסה. כל ההגדרות (משתמשים,
תוכניות, מצבים, יומן) נשמרות בנפח הקבוע של התוסף (`/data`), שורדות הפעלה-מחדש
ועדכון-גרסה, ונכללות בגיבוי של HA.

## חיבור ה-MQTT

התוסף מקבל אוטומטית את פרטי החיבור ל-Mosquitto המקומי דרך Home Assistant —
אין צורך להגדיר כתובת, משתמש או סיסמה ידנית. ההגדרות `mqtt_url`/`mqtt_user`/
`mqtt_pass` נחוצות רק אם בחרת ברוקר חיצוני, ואז הן גוברות.

## התקני Home Assistant (תאורה, מזגן, תריסים ועוד)

מעבר לממסרי ה-Tasmota, אפשר לחבר לדשבורד כל התקן ש-Home Assistant שולט בו —
`switch`, `light`, `fan`, `input_boolean`, `cover`, `lock`, `climate`:

1. עבור ללשונית **🏠 התקנים** בממשק ולחץ **רענן**.
2. סמן את ההתקנים הרצויים ולחץ **הוסף נבחרים**.
3. כל התקן מקבל מספר ממסר משלו (מתחיל אחרי ממסרי ה-Tasmota), ומאותו רגע הוא
   מתנהג כמו כל ממסר אחר: הרשאות, תוכניות, מצבים ושליטה טלפונית עובדים עליו.

אין צורך להזין כתובת HA או Long-Lived Token — התוסף מדבר עם HA דרך הנתיב הפנימי
של ה-Supervisor (`supervisor/core/api`), שלא תלוי ב-mDNS או בכתובת רשת כלשהי.
השדות בממשק נשארו כמנגנון גיבוי להרצה מחוץ ל-Add-on.

המצב מתעדכן **בזמן אמת** דרך WebSocket ל-Home Assistant: שינוי שנעשה מחוץ למערכת
(אפליקציית HA, מתג-קיר, אוטומציה) משתקף מיד בדשבורד. במקביל רצה סקירה כל 30 שניות
כרשת-ביטחון, ושמות ההתקנים מסונכרנים אוטומטית מ-HA.

תריסים, מנעולים ומזגנים מטופלים לפי סוגם: "הדלקה" של תריס פותחת אותו
(`open_cover`), של מנעול — פותחת (`unlock`), ומזגן נחשב פועל בכל מצב שאינו `off`.

## עדכון גרסה

הקוד נצרב לתוך תמונת הקונטיינר בזמן הבנייה — מה שנבנה הוא מה שרץ, ואין הורדת
קבצים מהאינטרנט בכל הפעלה. כדי לעדכן: העלה את מספר הגרסה ב-`config.yaml`, דחוף
ל-GitHub, ואצל הלקוח יופיע כפתור **Update**.

## פתרון תקלות

- **"אין ברוקר MQTT"** ביומן → ודא שהתוסף Mosquitto broker מותקן ופועל, או מלא `mqtt_url`.
- **הבקרים לא מגיבים** → ודא שה-Tasmota מוגדר ל-MQTT Host = כתובת ה-IP של ה-Pi,
  ושה-`topic` בהגדרות תואם בדיוק לשם הבקר.
- **התקני HA לא מגיבים** → ודא ש-`homeassistant_api: true` קיים ב-config.yaml של התוסף.
  ביומן ההפעלה אמורה להופיע השורה "תקשורת-HA דרך הנתיב-הפנימי".
- **שליטה טלפונית לא עובדת** → `/yemot` חייב להיות נגיש מהאינטרנט דרך פורט 3000;
  Ingress לא מתאים לכך כי הוא דורש אימות של HA.
- צפה ביומן התוסף בלשונית **Log**.
